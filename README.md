# Tulas International School — Homepage Redesign

A responsive React homepage redesign for Tulas International School (TIS), using the school's official website for verified brand details, links and photography.

## Tech Stack

- React 19 and TypeScript
- Vite
- Framer Motion
- CSS
- Lucide React

## Features

- Responsive navigation with a mobile menu
- Hero entrance animation and scroll-triggered section reveals
- Smooth scroll progress indicator
- Academics, campus, school-life and admissions sections
- School photos, logo and official social links
- Contact form with required-field and email validation
- Accessible labels, reduced-motion support, descriptive image text and SEO metadata
- Responsive layouts checked at desktop, tablet and mobile widths

## Run Locally

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```

## Contact Form

The enquiry form validates in the browser and displays a confirmation. It does not transmit enquiries; connect it to an admissions API or form service before using it to collect real submissions.

## Content Notes

School facts and contact details are limited to information published by TIS. No student counts, campus statistics or testimonials have been invented. School photography and the logo load from the official TIS website.

## Deployment

The project is configured for Vite and can be deployed by importing the repository into Vercel or Netlify. No live deployment or public GitHub repository is connected from this workspace yet.
